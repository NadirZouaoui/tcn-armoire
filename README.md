# tcn-armoire

Fiche QR de l'armoire d'injection — Tetra Canette.

Le QR collé sur l'armoire pointe vers <https://nadirzouaoui.github.io/tcn-armoire/>,
une page mobile autonome qui affiche les caractéristiques de l'installation
(champ PV, arrivées onduleur, injection vers le PDL).

Voir [HANDOFF.md](HANDOFF.md) pour le déploiement, la régénération du QR et les
points restant à trancher avant impression.
